Arvore AVL em Python

Implementação de uma Arvore AVL (Adelson-Velsky e Landis) desenvolvida em Python para a disciplina de Estrutura de Dados.

O projeto demonstra o funcionamento de uma árvore binária de busca autobalanceada, que mantém seus fatores de balanceamento entre -1 e 1 após as operações de inserção e remoção.

Funcionalidades

- Inserção de números inteiros.
- Remoção de elementos.
- Busca de valores.
- Rotações de balanceamento LL, RR, LR e RL.
- Percursos em pré-ordem, em ordem e pós-ordem.
- Exibição da altura da árvore.
- Exibição dos fatores de balanceamento dos nós.
- Visualização da estrutura da árvore no terminal.
- Menu interativo.
- Tratamento de valores duplicados e buscas ou remoções de elementos inexistentes.

Tecnologias utilizadas

- Python 3

Pré-requisitos

Ter o Python 3 instalado no computador.

Para verificar a instalação, execute este comando no CMD:

python --version


Como executar

1. Clone este repositório:
git clone https://github.com/juuhbronse334-alt/Atividade-Arvore/tree/main


2. Entre na pasta do projeto:
cd atividade-avl


3. Execute o programa:
python arvore_avl.py


No Windows, também é possível utilizar:
py arvore_avl.py


Menu do programa
O sistema disponibiliza as seguintes opções:

1. Inserir elemento
2. Remover elemento
3. Buscar elemento
4. Exibir percursos
5. Exibir alturas e fatores de balanceamento
6. Visualizar árvore
0. Sair

Conceitos aplicados:

- Árvores binárias de busca.
- Recursividade.
- Altura de nós.
- Fator de balanceamento.
- Rotações simples e duplas.
- Inserção e remoção em árvores autobalanceadas.

Objetivo acadêmico

Aplicar os conceitos de árvores binárias de busca autobalanceadas, desenvolvendo uma implementação própria de uma Árvore AVL, sem utilizar bibliotecas prontas para esse tipo de estrutura de dados.
